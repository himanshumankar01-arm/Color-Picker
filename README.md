# Pick a Color (React + Vite)

Click the big panel to go to the next color, or click any color button to jump to it.

## Run it

You need Node.js 18 or newer.

```
npm install
npm start
```

Then open the address shown in the terminal (usually http://localhost:5173).

## Build for production

```
npm run build
```

The finished site is written to the `dist` folder.

## Add or change colors

Edit the `COLORS` list at the top of `src/App.jsx`. Each color has a `name`, a background `bg` and a text color `ink`.
